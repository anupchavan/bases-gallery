# Bases Gallery

An Obsidian plugin that adds a **Gallery** layout to [Bases](https://help.obsidian.md/bases).

Requires Obsidian 1.13.0 or later, with **Bases** turned on in **Settings → Core plugins**.

## Install

Until the plugin is in the community store, install it with [BRAT](https://github.com/TfTHacker/obsidian42-brat): add `anupchavan/bases-gallery` as a beta plugin, then enable **Bases Gallery** in **Settings → Community plugins**.

## Usage

In a base, add a view and pick **Gallery** as its layout.
