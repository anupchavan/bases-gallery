# Bases Gallery

An Obsidian plugin that adds a **Gallery** layout to [Bases](https://help.obsidian.md/bases).

Requires Obsidian 1.13.0 or later.

## Development

```bash
npm install
npm run dev     # watch build
npm run build   # production build
npm run lint
```

Copy `main.js`, `manifest.json` and `styles.css` into `<Vault>/.obsidian/plugins/bases-gallery/` of a test vault, then enable the plugin in **Settings → Community plugins**.
